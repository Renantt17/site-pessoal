# Etapa 1 — HTML puro

Nesta primeira etapa, desenvolvi a estrutura do meu site pessoal utilizando somente HTML, sem aplicar estilização com CSS. O objetivo foi organizar as informações e conhecer melhor as tags utilizadas na construção de uma página web.

## Estrutura utilizada

- `<!DOCTYPE html>`: informa ao navegador que o documento utiliza HTML5.
- `<html lang="pt-BR">`: define o idioma principal da página como português brasileiro.
- `<head>`: reúne informações sobre o documento, como codificação de caracteres, configuração de visualização e título.
- `<meta charset="UTF-8">`: permite a utilização correta de caracteres especiais, como acentos.
- `<meta name="viewport">`: configura a visualização da página de acordo com a largura do dispositivo.
- `<title>`: define o título exibido na aba do navegador.
- `<body>`: contém todo o conteúdo visível da página.

## Organização do conteúdo

Para separar e organizar as informações, utilizei algumas tags semânticas:

- `<header>`: apresenta o cabeçalho do site, com meu nome, uma breve descrição e minha foto.
- `<main>`: identifica o conteúdo principal da página.
- `<section>`: divide o conteúdo em partes, como sobre mim, formação acadêmica, experiências profissionais, projetos, habilidades e contato.
- `<article>`: organiza informações específicas dentro de cada seção, como instituições de ensino, experiências profissionais e projetos.
- `<footer>`: apresenta o rodapé, contendo os links das minhas redes sociais.

## Elementos de conteúdo

Também foram utilizadas tags para apresentar textos, imagens, listas e links:

- `<h1>`: utilizado para o título principal da página.
- `<h2>` e `<h3>`: organizam os títulos e subtítulos das seções.
- `<p>`: utilizado para apresentar os textos e descrições.
- `<img>`: exibe minha foto de perfil. O atributo `alt` fornece uma descrição da imagem.
- `<ul>` e `<li>`: organizam as listas de linguagens, tecnologias e ferramentas.
- `<a>`: cria links para meus perfis no GitHub e LinkedIn.
- `<strong>`: destaca informações importantes, como cargo e período de experiência.

## Formulário de contato

Para criar a área de contato, utilizei:

- `<form>`: agrupa os campos do formulário.
- `<label>`: identifica cada campo e o relaciona ao seu respectivo elemento por meio do atributo `for`.
- `<input>`: permite inserir o nome e o e-mail, utilizando os tipos `text` e `email`.
- `<textarea>`: permite escrever uma mensagem com mais de uma linha.
- `<button>`: cria o botão para enviar a mensagem.
- `required`: atributo utilizado para indicar que os campos precisam ser preenchidos.

## Resultado

Ao final desta etapa, foi construída a primeira versão do site, com as informações organizadas e estruturadas utilizando HTML. A preocupação principal foi com a estrutura e o conteúdo da página, deixando a parte visual para a próxima etapa.
